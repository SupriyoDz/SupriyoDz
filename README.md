#### 🧠 [MindBridge — Teaching-Content-to-Review-Ready Artifact Generator](https://github.com/SupriyoDz/MindBridge)
> Client-side academic AI studio that turns raw teaching materials into 4 synchronized, review-ready artifacts (**Lesson Plan**, **Rubric**, **Flashcards**, **Quiz Bank**) calibrated by **Bloom's Taxonomy**.
<details>
<summary><b>🔍 Architecture & Highlights</b></summary>

- **Pure Client-Side SPA:** React, Vite, Tailwind CSS, Recharts, and PDF.js with a **Single Source of Truth (SSOT)** Content Map pipeline.
- **Model-Agnostic LLM Engine:** Auto-detects **Gemini**, **OpenAI**, **Claude**, **Groq**, **OpenRouter**, **DeepSeek**, **Mistral**, **Together AI**, and local **Ollama / LM Studio** via strict JSON schemas.
- **Pedagogical Calibration & Export:** Drift detection (>15%) with one-click recalibration, LO coverage matrix, item-level difficulty tuning, and **ZIP / Anki CSV / Print-to-PDF** export.

</details>

#### 🤖 [Jarvis — AI Personal Assistant](https://github.com/SupriyoDz/Jarvis_user-assistant)
> LLM-powered personal assistant with a responsive **Flask Web UI**, **CLI mode**, voice I/O, and a modular intent-to-action engine.
<details>
<summary><b>🔍 Architecture & Highlights</b></summary>

- **LLM & Fallback Engine:** Uses any **OpenAI-compatible API** (GPT-4o, Claude, local Ollama) for structured JSON intent/parameter extraction, with keyword-based fallback when offline.
- **Voice & Web Interface:** Speech-to-text & text-to-speech with graceful fallback, paired with a dark/light themed **Flask** web UI.
- **Modular Smart Actions:** Supports Wikipedia lookup, Google Search, YouTube, Spotify, Instagram, WhatsApp messaging, and SMTP email.

</details>

#### 🛒 E-Commerce Backend
